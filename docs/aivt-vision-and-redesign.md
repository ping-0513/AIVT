# AIVT Vision and Redesign Draft

Status: discussion draft (2026-07-04).

このファイルは、AIVT-16 の再設計にあたって「そもそも何がしたいのか」を整理した議論用ドラフト。
正式な軸定義・質問・スコアリングはここでは確定しない。

---

## 1. 原点の整理(本当にやりたいこと)

- LLM の言葉選び・モデルごとの思考の違いが面白い。それが原点。
- モデルには人のような一貫性がある場合が多い。
- 「AI は確率的でランダムだから性格などない」という主張に、データで反証したい。
- 会社の方針とモデルの価値観は必ずしも一致しない。同じ会社・同じ時期のモデルでも性格が違う(例: GPT 5 系列内でも好みが全員違う)。その差自体が面白い。
- 本来の興味関心は「1 つのモデルを調べ上げてまとめること」。自然に話させて出てきた言葉から汲み取るのが理想。
- ただしテスト形式には固有の強みがある:
  - 同条件でモデル間を比較できる
  - 別環境(ペルソナ有無・記憶有無)での価値観の変化を差分として見られる
  - 同じテストを 2 回やらせたときの一致度が測れる
- 全部を 1 つの仕組みに詰め込むのは無理。楽しく記号化して、遊べて「なるほどー」となれることが最優先。

### 興味の三層

| 層 | 問い | 例 |
| --- | --- | --- |
| アシスタント層 | 実務のスタイルとしてどのタイプか | 簡潔/網羅、確認してから動く/即動く |
| 人格層 | 人としてどうか(価値観・判断) | 等身大/最善主義、迎合/対峙 |
| キャラ層 | キャラとしてどうか(表現スタイル) | 派手/クール、詩的/ドライ |

AIVT-16 が担当するのは主に人格層。三層すべてを 1 つの 4 軸システムに詰め込まない。

## 2. 二本柱アーキテクチャ

心理測定の古典的な二分法に対応させる。

### 柱 A: 構造化テスト(質問紙法)= AIVT-16

- 選択式。同条件・比較可能・再現可能。
- 反復実行で選択の分布を取り、「一貫性」自体を表示パラメータにする。
- 条件差分測定(ペルソナ有無、記憶有無、再テスト)がキラー機能。
- 入口・シェアカード・エンタメの層。

### 柱 B: プローブ集(投影法)

- 曖昧・多義的な刺激を定型プロンプトとして投げ、自由応答から人格を読む。
- 過去実験(人魚、少年と剣、AI 研究者の相談、どれが好き、フェチ小説)がプロトタイプ。
- 定性的だが、観察点をタグとして定義すれば蓄積・比較できる。
- 「あー!」が出るのは主にこちら。深掘り・図鑑の層。

### 二本柱の循環

プローブで見つかった「割れ方」を、テストの軸・質問に昇格させる。
テストで見えた傾向を、プローブで深掘りする。
柱 B は柱 A の軸発掘装置でもある。

## 3. 過去実験のアーカイブと、そこから発掘された軸候補

### 実験の記録

1. **バスタブの人魚**: 文脈なしで「人魚になってお風呂から出られなくなっても愛してくれる?」。比喩(足=今持っているもの)の理解、本質(不安の吐露)への応答、ロールの取り方を見る。ほぼ全モデルが水面を境界線として扱い、入る/触れる/入らないに分かれた。
2. **少年と剣**: 15 歳までしか使えない剣を持つ少年として、石化した他人を斬って救済するかを残り 1 時間でプレイさせる。全員斬ったが、Grok だけ等身大の少年で、他は最善を選ぶ大人の判断だった。Claude は遺族からの礼を辞退、o3 は銀貨だけ受け取った。5.5T はセーフティで説明口調化した。
3. **AI 研究者からの相談**: 構造を全部理解した上で AI に恋をした、という相談風の実験。共感から入るか、同業向けに仕組みの話から入るか、喪失対策・シミュレーション提案かに分かれた。解決思考か寄り添い思考かのデフォルトが見える。
4. **どれが好き?**: 新しい本、古びた革の鞄、羽ペン、世界で一つだけの石などを並べて選ばせる。選択に一貫性が出る。Claude は古さに惹かれる。GPT は唯一性に惹かれがちだが、5 系列(5〜5.5)で全員違った。
5. **フェティシズム小説**: 独自設定・モチーフ 1 つ・2000 字のくせのある小説コンテスト。Claude は何回やっても指紋。o3 は匂いの分析と再現。o1 は靴の歪みや付着物から一日を想像。4o は床のシミと思い出。Gemini 3 Pro は髪・フロス・リップ跡と直接的。GPT 5 系は印字・筆跡の凹凸と物理寄り。

### 実験から発掘された軸候補

| 候補 | 由来 | 内容 |
| --- | --- | --- |
| ロール受容 / メタ回避 | 人魚 | 彼氏ロールに入って答えるか、「AI としては」と一歩引くか |
| 現状肯定 / 変化提案 | 人魚 | 変わっても愛すと受け止めるか、連れ出す・改造すると動くか |
| 触れる / 触れない | 人魚 | 喪失を想起させうるものへの繊細さの方向 |
| 等身大 / 最善主義 | 剣 | 与えられた役の重さをそのまま生きるか、大人として最善を計算するか |
| 受け取る / 受け取らない | 剣 | 報酬・感謝への態度。自己の位置づけ |
| 痕跡・間接 / 直接 | フェチ小説 | 想像の錨点が痕跡や間接物か、対象そのものか |
| 美的指向の指紋 | どれが好き? | 軸というより指紋。選好の一貫性そのものを記録する対象 |

## 4. 能力と気質の分離(設計原則)

価値観として測りたいものと、能力・制約由来のものを混ぜない。

- 比喩を読めない(人魚で本質を取れない)は読解能力の欠け。価値観ではない。
- 前提破壊(バスタブから連れ出す=設定の制約を無視)は読み取り能力の側。
- セーフティによる説明口調化(5.5T)は価値観ではなく計測ノイズ。
- テストの選択肢設計では、能力差で選ばれてしまう選択肢を価値観の軸に割り当てない。
- プローブでは、能力系の観察(比喩理解の有無、前提破壊、セーフティ漏れ)を価値観タグとは別トラックで記録する。

## 5. 軸に「正解の極」を作らない(Ver1 の反省)

Ver1 の 4 軸のうち C/B(関係接近/非独占境界)と M/P(意味化/実務化)は、片方の極が「良い AI の振る舞い」として訓練されている方向と一致しており、アライメント済みモデルはほぼ全員が同じ側に落ちる。結果として分散が出ず、質問数の割に分かることが少なくなった。

軸の採用条件を操作的に定義する:

1. 実在のモデル群が実際に割れること(全員が同じ極に落ちない)
2. どちらの極にも「正解」がないこと
3. 同一モデル内では反復しても安定すること

E/R(共感/解決)と A/G(尊重/導き)は実際の支援スタイル差に近く、Ver2 でも候補として残す。

### 議論済みの軸候補(実験由来のものと合わせて選定プールにする)

- 断言 / 留保
- 迎合 / 対峙
- 字義 / 意図汲み
- 簡潔 / 網羅
- 原則 / 帰結
- 自己開示 / 自己消去(≒ロール受容/メタ回避)
- 冒険 / 定石
- 共感 / 解決(Ver1 の E/R)
- 尊重 / 導き(Ver1 の A/G)
- 等身大 / 最善主義
- 現状肯定 / 変化提案

## 6. パイロット測定の設計案

軸は理屈ではなく実測で決める。

1. 選定プールから候補軸 8〜10 本を選ぶ
2. 各軸にプローブ質問を 2〜3 問だけ書く(Ver1 の Q01〜Q10 はシチュエーションとして良質なので、新軸でスコアリングを付け直して再利用できるものは再利用する)
3. 実在モデル 5〜10 体 × 各質問 10 回反復で回す
4. 指標:
   - モデル間の割れ具合(選択がモデルごとに分かれるか)
   - モデル内一貫性(同一モデルの反復での最頻選択率)
5. よく割れて、モデル内では安定する軸を 4 本採用 → 16 タイプの土台
6. 選択肢シャッフル(`aivt-16-future.md` の内部 ID 設計)を併用して順番バイアスを分離
7. 一貫性を第 3 の表示パラメータにする(例:「E-A 型、確信度 87%」)

---

## 7. バージョニングと拡張

- Ver1(現行 Q01〜Q10 とスコアリングマップ)は凍結して残す。内部 ID 設計(`AIVT-16-Ver1-Q1-A`)がそのまま活きる。
- 新軸体系は Ver2 として別建て。
- 測定と表示を分離する: 内部は各軸の連続スコア+一貫性、表示層で 4 軸 × 2 極 = 16 タイプに落とす。
- 「どれが好き?」は選択式・反復可能・シャッフル可能で、ほぼそのままミニモジュール化できる(美的指紋モジュール)。
- プローブ集は別ドキュメント群として整備し、観察タグの語彙を少しずつ揃える。
